# StreamVibe landing page

React + TypeScript + Vite landing page, built by converting Pixso designs into production
components.

## Getting started

```bash
npm install
npm run dev
```

See **[CLAUDE.md](./CLAUDE.md)** for the full tech stack, coding standards, project structure, and
commit conventions, and **[docs/pixso-workflow.md](./docs/pixso-workflow.md)** for the end-to-end
guide to converting a Pixso frame into a merged, tested page section.

## Commands

```bash
npm run dev            # start Vite dev server
npm run build           # typecheck + production build
npm run preview         # preview the production build locally
npm run typecheck       # typecheck only
npm run lint             # eslint
npm run format           # prettier --write
npm run test             # unit tests (vitest)
npm run test:e2e         # e2e + accessibility tests (playwright)
```
